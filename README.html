Icecamera

Standalone development repository for Amundsen camera ice classification, seawater triage, image similarity and projection experiments.

Current status

  • The conservative tree-based seawater filter is inline with the live Gemma worker. Image-similarity label propagation is the next experiment; it has not been implemented or validated yet.
  • Models, labels, photo caches, result JSON and viewers remain in their existing locations. This migration does not duplicate or delete those datasets.
  • Existing source files in Amundsen are retained as a rollback snapshot. All further experimental development belongs here. The running underway dashboard is not changed.
  • After testing, export one clean script into Amundsen with explicit input/output paths, no dependency on this development repo, and fail-open filtering.

Layout

  • tools/: experimental workers, training, review and projections.
  • dashboard/: compatibility package containing extracted camera helpers only, not the web application.
  • tests/: focused camera and queue tests.
  • ops/: ignored machine-local service templates; inspect before installing.

Data

2026 originals: /data/scratch/camera-originals. 2025 originals: local T7 SSD. Outputs and labels: /home/cryomics/Downloads. The model server remains shared with crew chat; no extra model is automatically loaded.

Development

Use the existing Miniforge Python. Run OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 /opt/miniforge3/bin/python3 -m unittest discover -s tests here. The extracted scripts still contain machine-local data paths; making these configurable is part of the eventual clean-script export.

Next experiment

Evaluate actual ROI similarity and short temporal runs, grounded in reviewed water examples, with independent checks for ice transitions and outliers. Do not propagate from t-SNE proximity alone. Preserve label provenance, retain original photos, and audit bypassed candidates. Target useful throughput, not a claim of exact scientific ice absence.
